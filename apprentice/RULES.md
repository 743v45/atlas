# apprentice — 记录规则

一课一目录，记「怎么把意图交给 AI」。主语永远是学徒（我），不是 AI。

## 1. 什么算一课

- 从**真实对话**里长出来的方法，回答一个具体症状下的问题（「AI 理解总偏」「输出不稳定」）。
- **禁止凭空创作方法论**——想出来的课看起来一样整齐，但没有走过。可追溯（meta.source）是这条的执行手段。
- 一课 = `items/<类别>/<课>/{meta.json, lesson.md}`。类别枚举：`express`（表达）、`drift`（防漂移）、`prune`（修枝/取舍）、`automate`（固化/自动化）、`verify`（验证）。新增类别须在此登记。
- **结构判据（何时拆类别 / 上域）**——与 pick 的分层判据同源：
  - 一层值得存在 ⟺ 它回答一个别的层不回答的问题，且有独立生命周期——否则是伪层级。
  - **类别 >7±2 个 → 引入域**（domains.json，索引页改列域）；**单类别 >9 课 → 横向拆类别**，不加深层级。build 会对超限类别出预警（warn 不 fail）。
  - 一课值得独立存在 ⟺ 有独立的症状与验证方法；只是同一方法的变体 → 并入已有课的正文，记入变更记录。

## 2. meta 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| name | ✓ | 课名 |
| question | ✓ | 回答的问题，一句话 |
| status | ✓ | `settled`（定案，默认）/ `outdated`（过期）——**收录即定案**，无「在学」态 |
| date | ✓ | 首次沉淀日期 |
| verified | ✓ | 最后验证日期；超 180 天索引标「待重验」 |
| model | ✓ | 在什么模型上验证——时效锚点，模型换代后技巧会过期 |
| symptoms | ✓ | 症状标签，非空数组。索引反查的锚点，写用户真会搜的词，不写术语黑话 |
| source | ✓ | 原始对话存档（日期 + 会话标识；未归档标「待归档」） |
| artifacts | | 沉淀产物路径数组（模板 / skill / 规则文件），相对本库根。**写了就必须存在** |

## 3. 写作规范

- **结论先行**：TL;DR 一句话，正文每节直给，不铺垫。
- **例子优于形容词**：判据一律用正反例演示。「提取重点」是雾词，「提取像这段一样的内容」是路标。
- **验证段必填**（`## 验证`）：写可执行的验证动作（复述关 / 同输入对比 / 格式锚点……）。没有验证段的课不进索引——build 门禁会拦，这是「强制优于记忆」的落地。
- **翻车记录必填**（`## 翻车记录`）：记翻车的原始表述与修正；暂无翻车写「暂无」。失败比成功教学价值高，不记它，系列会变成只讲漂亮话的选集。
- **收录即定案**：课是结论馆，不是草稿箱——走出结论、验证通过才建课；在学 / 半成品不进库（留在对话里，走通了再沉淀）。唯一的后续变迁是失效：模型换代后失效 → `outdated`，并在时效小节写清失效原因与替代。

## 4. 图纸与公路对账

- 课 = 图纸；沉淀出的模板 / skill / CLAUDE.md 规则 = 修好的路。
- 两者必须互相指向：课的 `artifacts` 指向真实文件；文件头注一行来源课（如 `来自 apprentice/express/describe-the-goal`）。
- 改路（修模板 / skill）当天更新图纸，反之亦然。图纸不跟公路对账，雾就又起来了。

## 6. 生成物与门禁

- 所有 HTML（`index.html`、各课 `lesson.html`）由 `python3 scripts/build-index.py` 生成，**禁止手改**。
- 门禁项：必填字段、status 枚举、日期格式（YYYY-MM-DD）、`## 验证` 与 `## 翻车记录` 小节、artifacts 路径存在性。任何错误 → 退出码 1，索引不更新。
- 校验只认代码，不认自觉：规则改了先改 build，再改文档。
