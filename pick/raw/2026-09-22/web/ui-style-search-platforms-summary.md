# UI 风格搜索平台 · 天花板与口碑汇编

## 一、真实产品 UI 截图/流程库（查真实实现）

| 平台 | 规模/能力 | 口碑要点（含时间） |
|---|---|---|
| **Mobbin** | 500k+ screens / 1,000+ apps（coolcuration 2026），600k+（Mobbin MCP 官宣 2026-08）；iOS/Android/Web；按 app/flow/screen type 筛；Figma 插件 + MCP | 设计师社区公认 indispensable（r/UXDesign、官网证言）；"way better for real design inspo [than Dribbble]"（2026-05 Instagram 评论）；**Trustpilot 2.5/5 Poor（2026-06）**：免费层几乎没内容、paywall 骚扰；free tier = 仅最新 app + 有限搜索 + 3 collections；Pro ≈ £8/月（年付，UK，2026）；2026 有 "Did Mobbin get worse" 讨论 |
| **Refero** | real product screens/flows/patterns；按 section/tag/文本内容搜（uxcel）；"Design research for humans and AI"（Refero 2.0，PH #3 of the day 2024-08） | PH 口碑好：strong search/filters、real products not concept shots；与 Mobbin 直接对标（r/UI_Design 有 "refero or mobbin" 抉择帖） |

## 三、Moodboard / AI 视觉搜索

| 平台 | 定位 | 口碑要点 |
|---|---|---|
| **Cosmos**（cosmos.so） | AI 视觉搜索：按色板/风格/时期/材质搜、Find Similar、clusters；有 iOS App | 被捧 "the new Pinterest for designers"（Midwest Design）；Qdrant 官方案例 "editorial-grade visual search"（2025-11）；**但有 astroturfing 指控**（r/Design："Cosmos who has astroturfed before"、"I work for Cosmos, AMA"）——营销痕迹重，好评采信打折 |
| **Savee** | 设计师收藏夹，自定义瀑布流 | medium 对比文 + reddit 均列 design-specific references 首选 |
| **Are.na** | 研究型链式收藏（research trails） | 设计师+学术圈 favorite（reddit："better for curated research trails"）；15 年仍独立运营（官网 2026-09） |
| Pinterest | 量最大 | **AI slop 重灾区**："Pinterest Is Dead – AI Slop Killed It"、官方 AI 标注/tuner 失效、"unusable now between the ads and AI"（设计师，r/Pinterest 2025-26）；Wired 在收料报道；作为 UI 风格源已不可靠 |

## 四、设计社区

- **Behance**：完整 case study，免费，仍可靠（深度参考）。
- **Dribbble**：**口碑崩塌中**——r/UXDesign "I wish Dribbble would come back"（half-baked concept shots）、"real design examples disappeared"、AI slop 疲劳（r/UI_Design 2025-26）；2026 文章普遍降级其为"aesthetic direction"用途，不复是真实参考源。
- **Muzli**：仍运营（"12 years of curated inspiration"，官网 2026），聚合 feed/新标签页定位，存在感下降，非搜索库。

## 五、垂直风格素材

- **Typewolf**：字体趋势 What's Trending in Type（更新至 2025-12）+ 字体配对速查。
- **Fonts In Use**：真实作品按字体归档，按 typeface/topic/年份筛。
- **Scrnshts**（scrnshts.club）：App Store 截图策展，免费干净（neoads 2026）；同类新玩家 appshot.gallery / appshots.design（ASO 向）。

## 六、结论草案（每场景的天花板）

1. 真实 App/Web UI 查实现 → **Mobbin**（付费天花板）；搜索体验 challenger → **Refero**
2. 完整用户流程 → **Page Flows**（录屏）/ **Nicelydone**（SaaS 静态）
3. 网站视觉风格 → **Godly**（品味）/ Awwwards（风向，带可用性保留）
4. 落地页 → **Land-book**（综合）/ SaaS Landing Page（SaaS + tech stack 筛选）
5. 以图搜图/moodboard → **Cosmos**（AI，口碑打折）/ Savee + Are.na（人工策展）
6. 排版 → Typewolf + Fonts In Use；App Store 截图 → Scrnshts

**口碑雷区**：Dribbble（concept+AI slop）、Pinterest（AI slop）、Cosmos（astroturfing 指控）、Mobbin（产品强但免费墙差评）、2026 SEO 新玩家（无独立口碑）。
