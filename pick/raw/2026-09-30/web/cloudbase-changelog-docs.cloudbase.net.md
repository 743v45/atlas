2026-05-28​                                                                      

【集成中心】：第三方服务一站式接入​                                              

CloudBase 推出 集成中心（Integration                                            
Center），将微信支付、微信公众号等第三方服务封装为开箱即用的「集成」。开发者无需
自行管理凭证、处理验签解密、维护回调域名，在控制台填写一次配置即可生成对应的云函
数与回调链路。查看功能介绍 →                                                    

已支持的集成类型：                                                              

 • 微信支付：小程序支付 / JSAPI 网页支付 / Native 扫码支付                      
 • 微信公众号：公众号开放服务（网页授权、用户消息、模板消息、自定义菜单等）     

核心价值：                                                                      

 • 凭证统一托管：API 密钥、证书、私钥由平台管理，不进入业务代码                 
 • 回调代收代验：自动接收第三方异步通知，验签解密后以明文转发给业务函数         
 • 一键部署函数：创建集成时自动生成 HTTP 云函数模板，业务侧仅需补齐业务逻辑     

详情请参考：集成中心文档 · 使用流程 · 常见问题                                  

2026-03-30​                                                                      

【平台能力】：云开发环境可作为云资源进行ICP备案​                                 

过去云开发环境不支持作为备案云资源进行域名备案。                                

本功能上线后，个人版及以上套餐的环境，若剩余有效期在6个月以上，且开启了固定IP， 
则可以直接在备案控制台拉取到满足条件的云开发环境，无需额外购买云服务作为备案云资
源。                                                                            

流程介绍​                                                                        

 1 前往备案管理                                                                 
 2 若不满足备案条件，按页面指引进行操作即可。                                   
 3 若满足备案条件。点击页面上方的“去备案”按钮，即可前往备案控制台进行备案。     

🌆 备案管理页面                                                                 

 1 在备案页面可拉取到符合条件的云开发环境作为备案云资源。                       

🌆 选择备案云资源                                                               

 1 进入备案申请流程，按ICP备案文档指引操作即可。                                

2026-03-11​                                                                      

【CLI / MCP / Skills】：支持设备码登录（Device Code Flow）​                      

CloudBase CLI、MCP Server 和 AI Skills 现已支持 设备码登录（Device Code         
Flow），适用于无浏览器环境或远端服务器场景（如云端 IDE、SSH 终端、云端 OpenClaw 
等），无需本地浏览器即可完成身份授权。                                          

设备码登录：远端开发场景的身份认证方案​                                          

传统登录方式的痛点：CLI 登录依赖本地浏览器跳转完成 OAuth                        
授权，在远端服务器、容器环境或云端 IDE 中无法直接使用。                         

设备码登录的优势：通过设备码（Device                                            
Code）解耦授权设备与登录设备，用户只需在任意浏览器中访问授权页面并输入设备码，即
可完成远端环境的身份授权。
