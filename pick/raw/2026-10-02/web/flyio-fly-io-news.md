# Fly.io 官方公告：Computers for Agents（fly.io/news，访问 2026-10-02）

- 来源：https://fly.io/news/fly-io-launches-computers-for-agents（WebFetch 全文提取）
- 公告日期：2026-07-24

## 要点

- **定位重塑**：为 AI agent 提供专用基础设施（「Computers for Agents」）；强调不是一次性 sandbox，而是「真计算机」——持久磁盘、安全连接、可扩展到数百万实例的生产级 agentic 负载。（本页未点名 Sprites；Sprites 见 daily.dev 报道）
- **融资**：**$25M Series D**，Dell Technologies Capital 与 Intel Capital 联合领投，a16z、EQT、Geodesic、YC 跟投；Martin Casado（a16z）、Daniel Docter（DTC）入董事会。
- **新 CEO**：**Scott Johnston**（前 Docker CEO；曾任 Puppet、Loudcloud、Netscape）。创始人 Kurt Mackey 转顾问、留董事会。
- **既有平台与客户**：公告不提关停/迁移既有 app 托管平台，而是讲连续性——**37,000+ 客户，其中 8,000+ 为 agent-native**；最大客户里 agent-native 约占 2/3 收入，top agent-native 客户收入 12 个月涨 ~12x。具名客户：Firecrawl、Kilocode、Plastic Labs。
- 引语：Casado——「这次用户不一定是人，这改变了计算机该长什么样」；Johnston——「agent 作为人的新界面，需要自己的真计算机」；Mackey——开发者「不该在『强大』和『好用』之间二选一」。

## 解读注意

- 官方口径是「连续性」而非「放弃旧平台」，但战略重心、融资叙事、首页版面全部押注 agent 负载；传统 web 托管客户从此是第二叙事。
