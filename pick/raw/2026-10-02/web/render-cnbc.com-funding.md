# CNBC：Render 融资报道（2026-02-17）

- 来源：https://www.cnbc.com/2026/02/17/render-raises-100-million-at-1point5-billion-valuation.html
- 访问日期：2026-10-02（WebFetch 直抓被域名校验拦，web_reader 取回全文）
- 标题：Cloud startup Render raises funding at $1.5 billion valuation as AI-built apps boom（Jordan Novet）

## 关键事实（原文摘录）

- 2026-02-17（周二）宣布融资 **$100M，估值 $1.5B**
- 创立 2018 年，总部旧金山，约 **100 名员工**
- 收入增速 "well above 100%"；**450 万开发者**使用其工具（CEO Anurag Goel 告诉 CNBC）
- 投资方：01A、Addition、Bessemer Venture Partners、General Catalyst、Georgian Partners（CNBC 未提本轮领投方）
- CEO Anurag Goel = Stripe 第 8 号员工
- 基础设施：跑在 AWS + GCP 上；近期在测试自有服务器（降本→可能降价；风险是要自备容量）
- 客户：Alibaba、CBS、Hodinkee、Paradigm、Shopify、Base44（AI 应用构建器，被 Wix 收购）
- **Heroku 动向**：Salesforce 于 2026-02（"earlier this month"）表示不再为 Heroku 开发新功能；Goel："People now know that they're not going to add new features to it, so they're looking around for the most mature alternative"
- **OpenAI Codex** 集成 Render 为部署目标（与 Cloudflare/Netlify/Vercel 并列）；OpenAI 自己也在用 Render
- Vercel 2025-09 融资估值 $9.3B；Goel 称有公司（如 AI 表格 Shortcut）从 Vercel 迁来 Render
- Goel："Chatbots have effectively, almost singlehandedly, grown our business."（ChatGPT 会在某些场景推荐 Render）
