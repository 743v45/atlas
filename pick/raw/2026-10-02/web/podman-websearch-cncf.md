# Podman 捐入 CNCF — WebSearch 聚合

- 来源 URL: WebSearch 聚合页（查询词 "podman CNCF podman-container-tools organization Red Hat donate"，经 z.ai web_search_prime）
- 访问日期: 2026-10-02

## 关键事实（聚合摘要）

- **2024-11 KubeCon + CloudNativeCon NA**：Red Hat 宣布向 CNCF 捐赠整套容器工具：**bootc、Buildah、Composefs、Podman、Podman Desktop**（Skopeo 同属 podman-container-tools 项目）。
- 项目现以 **"Podman Container Tools"** 名义列于 cncf.io 项目页，描述为「无 daemon 管理容器/镜像生命周期的工具集（Podman、Buildah、Skopeo）」。
- GitHub 组织随之迁至 `podman-container-tools`（与 v6.0.0 release notes 的 import 路径变更 `go.podman.io/podman/v6` 互证；原 `containers/podman` 地址 GitHub 自动重定向，gh api 2026-10-02 仍可访问）。
- Podman Desktop 的 CNCF 迁移博客（2024-11-14）确认社区驱动进入 CNCF。
