# Docker Desktop 许可门槛（250 员工 / $10M 营收）

- 来源：WebSearch（Z.ai web_search_prime 聚合），查询词「Docker Desktop licensing 2025 pricing 250 employees $10 million revenue Pro subscription requirement」
- 访问日期：2026-10-02

## 关键事实（搜索聚合）

- Docker Desktop 免费对象：员工 **<250 且年营收 <$10M** 的小企业、个人、教育、非商业开源项目
- 商业使用在企业 **>250 员工 或 >$10M 年营收** 时需付费订阅（Pro / Team / Business 任一层）
- 该规则 2021 年引入（当时引发大量争议），至今仍然有效
- 免费条款出处：docs.docker.com/subscription-billing/desktop-license（官方文档）
- Docker Engine 本身（开源、Linux daemon）免费不受此限；收费限制只针对 Docker Desktop
- 超限企业须为**每个**跑 Docker Desktop 的开发者付费，推动部分组织转向 Podman / Rancher Desktop
