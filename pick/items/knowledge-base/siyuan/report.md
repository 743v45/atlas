## 为什么（未 pick）

- **块级引用更细**：粒度比 `[[文件级]]` 双链细，这是它的差异化 [2]。
- **数据库形态仍被否**：数据是自管的 .sy 内容 + 内核索引，非纯 Markdown——不可 diff / grep / agent 直读写。v3.8.0 的 MCP + Agent 把 AI 通道从「无」升级为「官方一等公民」，但通道本质仍是 **API 层**（HTTP/MCP），依赖思源内核在线代理，而非文件系统原生访问——与「AI 对存储层的原生访问权」命题仍隔一层（2026-08-25 会话排除理由：「数据库型工具牺牲通用性换块级引用」）[2][3]。
- 中文原生 + Docker 自建同步是加分项 [2]。
- **值得肯定的趋势**：它是 2026 年数据库型笔记中 AI 转向最激进的一个（官方智能体 + MCP + 语义搜索全套），若未来提供「纯 Markdown 存储模式」值得重评（待验证）[3]。
