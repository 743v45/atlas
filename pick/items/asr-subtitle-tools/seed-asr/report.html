豆包 Seed-ASR（火山引擎 API）

TL;DR：字节豆包 Seed-ASR 云 API：普通话平均 CER 3.69% 的闭源顶配（FireRedASR2 官方对比口径），录音文件 1.8 元/小时还带热词/替换词杠杆；无本地权重，隐私敏感场景出局。
  • 结论：trial 试用（可接受云 API 时的中文准确率顶配路线）
  • 核实日期：2026-08-27

基本信息

项值来源
版本Seed-ASR 系（大模型流式语音识别，豆包语音家族）；对比口径含 2026-02 基准[1]
许可证商业闭源（按量计费，非 SPDX 开源许可）[2]
仓库/入口火山引擎控制台，无公开权重仓库（「仅论文，无权重与部署代码」——2026-08-24 调研结论）[1] [2]
维护活跃度商业服务持续迭代（计费/功能页活跃，观察 2026-08-27）[2]

为什么值得试用

  1. 闭源阵营顶配：第三方统一口径（FireRedASR2 官方 24 测试集对比，2026-02）普通话平均 CER 3.69%——仅次于 FireRedASR2-LLM（2.89%）与 AED（3.05%），优于 Qwen3-ASR（3.76%）与 Fun-ASR（4.16%）；方言 15.39% 略逊于开源头部 [1]。
  2. 字幕场景专属杠杆：热词（人名/术语/产品名）、替换词、ITN 文本规范化、多方言、长视频无截断（火山引擎文档，2026-08-24 调研汇总）[3]——开源方案普遍缺热词机制，这是纠专有名词错字最直接的武器。
  3. 价格门槛极低：录音文件识别标准版 0-300 小时档 1.8 元/小时（量增递减至 0.9 元），极速版 3.5 元/小时，有免费试用额度（火山引擎计费页，2026-08-24 查询）[2]——30 分钟视频约 0.9 元。
  4. 省运维：无模型下载、无 CPU/内存占用、无启停管理——与本地路线（见 fireredasr-ui）的运维成本成对照。

为什么不是 adopt

  1. 本地部署不可能：字节未开源模型权重与部署代码，隐私敏感/离线场景直接出局（2026-08-24 调研结论）[1]。
  2. 本项目主线是本地/免费：历史决策链（2026-08-24）最终选了本地 FireRedASR——准确率足够且零边际成本。
  3. 数据出域：素材上传第三方云。

对比

准确率与 FireRedASR2 同档（差距 <1 个百分点，统一口径 2026-02 [1]）；本地免费路线已覆盖需求时，云 API 的增量价值主要在热词纠错与免运维。逐维度见 ../comparison.md。

风险与注意

  • 价格与额度为 2026-08-24 查询快照，采用前以计费页为准。
  • 「待验证」：热词对英文专名（历史实测痛点：FireRedASR 系英文专名误差）的实际改善幅度。
