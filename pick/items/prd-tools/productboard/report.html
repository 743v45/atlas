Productboard

TL;DR：面向「大量用户反馈聚类成 roadmap」的需求管理平台：AI 聚类反馈强、PRD 起草弱（Essentials $19 / Pro $59 per maker/月，2026）；个人与小团队为此付费不值——它解决的是你没遇到的反馈规模问题。
  • 结论：hold（观望——不推荐个人/小团队新采用；反馈规模化后再评估）
  • 核实日期：2026-08-27

基本信息

项值来源
形态SaaS 产品管理平台（反馈聚合 + 优先级 + roadmap + 门户）[1][2]
价格2026：Essentials $19/maker/月（年付，月付约 $25）；Pro $59/maker/月（年付）[3]
定位「AI 聚类反馈与 roadmap 最强」（Storyflow 2026 评语）[2]

为什么 hold

  • 它不是 PRD 写作工具：强项是把大量用户反馈聚类、去重、映射到 feature 与 roadmap；PRD 生成在 2026 横评中被评「比现代替代品更重更贵、PRD 生成浅」（BuildBetter 2026）[4]、「customer call 证据整合才是核心」是同类证据派的共识（Enterpret 2026-07）[3]。
  • 价格按 maker 计费：Essentials $19、Pro $59 per maker/月（2026）[3]——没有反馈洪流要治理的团队，为「写 PRD」付这笔钱完全错位（2026-08-26 会话结论）[5]。
  • AI 共建时代无 agent 通道：无公开的 MCP/API agent 读写路径，「开发时 AI 消费 PRD」的工作流走不通（推导自公开集成面，2026-08-27 核实；待验证）。

何时重新评估

  • 用户反馈量大到需要专职聚类（支持、销售、社区多源汇总）且要客户门户/投票/roadmap 对外时——那时它对位的是 Enterpret、BuildBetter、Aha!（$59/user/月，BuildBetter 2026 [4]）这类「证据聚合」赛道，而非本类其他条目。
