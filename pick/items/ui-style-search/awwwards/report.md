# Awwwards

> **TL;DR**：获奖网站风向标：视觉天花板但口碑分裂——可用性常被批「bad practices」，当风向标用别当范式抄。

- **结论**：trial 试用
- **核实日期**：2026-09-22

| 项 | 值 | 来源 |

## 为什么选（作为 trial）

- **视觉风向标地位无可替代**：「award-winning, trend-forward web work」的代表（2026-09 AI 综述口径），要找「今年顶级站长什么样」它仍是第一入口 [4]。
- 筛选维度全：type/technology/color/industry + mobile gallery [2]。

## 为什么不是 adopt

- **可用性口碑分裂**：r/web_design「Something like awwwards but good?」直指「the joke that is awwwards… a compilation of bad practices」——获奖导向催生炫技而牺牲可用性的结构性批评 [3]。
- 提交收费制带来「付费入围」利益相关质疑（$49-169 门槛）[2]。
- 风格单一化：获奖审美趋同（重动效的 agency 风），找克制/实用风格反而不合适。

## 对比

- vs Godly：同为顶级视觉，Godly 无评审制争议；Awwwards 多竞赛数据（获奖历史可查）。
- vs CSS Design Awards：第二梯队同模式（提交 $25–60），备胎位。

## 风险与注意

- 把获奖站当「范式」抄会带入可用性问题——社区批评的正是这个用法 [3]。
- 无 gh stats（商业闭源）。
