## 为什么值得关注

- **国内最大设计师社区**（「国内最具影响力的设计师互动平台之一」口径，2025-06 盘点）——国内网络环境下零门槛可访问，且中文语境作品（本土品牌/活动页）是海外平台覆盖空白 [2]。
- 内容形态全：作品+赛事+毕业展（广美/央美等院校线上展）——追踪国内设计风向有效 [3]。

## 为什么只是 assess

- **作为「UI 截图/实现参考库」形态不匹配**：站酷是展示社区而非结构化截图库——无 flow 组织、无 screen type 检索，同类需求海外平台（Mobbin/Refero）降维覆盖。
- 国内导航站将其与 UI 中国、DOOOOR 并列推荐，但 2025-26 独立深度口碑样本少（多为导航站收录层证据）[4]。

## 对比

- vs Mobbin：不同物种——站酷是社区媒体混合体，Mobbin 是结构化参考库；国内可访问性是站酷唯一不可替代点。
- vs UI 中国 / 优设：同类国内平台（优设偏文章/教程，UI 中国偏 UI 社区），本轮未单独立目，见设计树落选节点。

## 风险与注意

- 商业化程度加深（PRO 计划、课程导流）对内容纯度的影响**待观察**。
- 无 gh stats（商业闭源）。
