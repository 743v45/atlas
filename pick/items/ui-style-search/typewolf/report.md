# Typewolf

> **TL;DR**：排版风格速查标准器：trending 字体 + 配对 + 按字体看实站；与 Fonts In Use 组合覆盖排版灵感。

- **结论**：trial 试用
- **核实日期**：2026-09-22

## 基本信息

| 项 | 值 | 来源 |
|---|---|---|
| 形态 | 字体趋势 + 配对速查站：What's Trending in Type / Site of the Day / 字体配对指南 | [1][2] |
| 活跃度 | What's Trending 持续日更（样本见 2025-12 条目） | [2] |

## 为什么选（作为 trial）

- **「UI 风格」的排版轴由它兜底**：看「今年实站都在用什么字体」有 What's Trending（带实站截图与字体标注，日更）；配对决策有字体配对速查 [1][2]。
- Google Fonts 精选清单持续维护（2026 版 40 best，含 Instrument Sans / Bricolage Grotesque 等新面孔）——免费字体选型的快捷入口 [3]。
- 排版垂直的互补组合：Fonts In Use 提供真实作品按字体归档（可按 typeface/topic/年份筛，「build a type pairing」场景的直接素材库）[4]。

## 为什么不是 adopt

- 单一垂直（排版），只是 UI 风格的一个轴；独立成库的覆盖不及综合平台。
- 部分深度内容（配对指南/recommendations）为付费产品，免费边界**待验证**。

## 对比

- vs Fonts In Use：Typewolf 管「趋势+推荐」，Fonts In Use 管「真实作品考古」；组合使用覆盖排版灵感全场景 [4]。
- vs 字体市场（MyFonts 等）：Typewolf 是策展/速查，不卖字体。

## 风险与注意

- 无 gh stats（个人运营站，长期稳定性靠历史记录背书）。
