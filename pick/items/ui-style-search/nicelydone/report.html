Nicelydone

TL;DR：SaaS 真实 UI 静态库第一梯队：199,600+ screens / 12,500+ flows（官网 2026-09）；SaaS 场景可平替 Mobbin。
  • 结论：trial 试用
  • 核实日期：2026-09-22

基本信息

项值来源
形态商业闭源：SaaS 产品真实 UI 截图库，按 product / flow / component 组织[1]
规模199,600+ screens / 500+ SaaS products / 12,500+ flows / 29,200+ components（官网 2026-09-22 快照）[1]
定位「Not Dribbble concepts. Not Behance mockups. Real products, captured in full.」[1]

为什么选（作为 trial）

  • SaaS 垂直规模已进第一梯队：2026 盘点口径 197,200+ screens（一个月内官网口径涨至 199,600+，周更中）[1][2]。
  • 「链接可引」的研究工作流：官网卖点「"Make it like Stripe's pricing page" hits different when you can link to it」——把参考变成可分享链接，贴合 PRD/评审场景 [1]。
  • 2026 年 Mobbin alternatives 盘点的常客 [2]。

为什么不是 adopt

  • SaaS 单垂直，App/移动端覆盖不及 Mobbin；规模亦小一个量级（199k vs 500k+）。
  • 独立第三方口碑样本仍少于 Mobbin/Refero（多为盘点文提及，非深度长测）——口碑样本量待沉淀。

对比

  • vs Mobbin：SaaS/web 重度团队 Nicelydone 够用且更专；移动端必须 Mobbin。
  • vs Refero：同为 web 强项，Refero 搜索粒度更细，Nicelydone 组件库组织更全。

风险与注意

  • 商业闭源，无 gh stats 可刷；免费层限制细节未核实（待验证）。
