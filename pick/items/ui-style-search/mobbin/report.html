Mobbin

TL;DR：真实产品 UI 截图/流程库的付费天花板：三端覆盖 + flow 组织 + Figma/MCP 生态；Trustpilot 差评集中在免费墙而非产品力。
  • 结论：adopt 推荐
  • 核实日期：2026-09-22

基本信息

项值来源
形态商业闭源 SaaS：iOS/Android/Web 真实产品截图 + 完整 flow[1][2]
规模500,000+ screens / 1,000+ apps（2026 评测口径）；Mobbin MCP 官宣口径 600,000+（2026-08-13）[2][4]
成本Free 层 + Pro ≈ $10/月（年付；UK 年付 £8/月，2026-08 评测）[2][5]
生态Figma 插件、团队 collection、Mobbin MCP（2026-08 发布）[1][4]

为什么选（adopt）

  • 覆盖与组织是硬差距：500k+ 真实截图按 app / flow / screen type / platform 组织，且按 flow 而非散图组织——「研究 onboarding 时拿到的是有序步骤而非随机截图」[2]。第三方盘点（colorlib 2026-03）将其单独列为「Mobile & web app UI patterns」品类且标注人工策展 [5]。
  • 社区口碑为赛道第一：r/UXDesign 讨论将其视为 UX/UI pattern 参考的默认工具；Instagram 设计圈评论「Mobbin is way better for real design inspo（than Dribbble）」（2026-05）[3]。
  • AI 生态卡位：2026-08 发布 Mobbin MCP，600k+ 设计库可被 coding agent 直查——「查真实实现」从人肉浏览延伸到 agent 通道 [4]。

风险与注意

  • Trustpilot 2.5/5「Poor」（2026-06-06 快照）：差评集中在免费层几乎无内容、paywall 全程遮挡、web 分类受限——是商业模式差评而非产品力差评；付费后口碑反转（coolcuration 长测「earns its keep」）[6][2]。
  • 免费层仅可浏览最新收录 app + 有限搜索 + 3 个 collection——把它当免费工具用会体验很差 [2]。
  • 2026 出现「Did Mobbin get worse」社区讨论（方向未证实，待验证）[7]。
  • 商业闭源，无 gh stats 可刷。

对比

  • vs Refero：Mobbin 赢在覆盖广度与 flow 组织；Refero 赢在 section 级搜索力（见 refero 条目）。
  • vs Page Flows：Mobbin 是静态截图库；「看流程怎么走」的录屏垂直归 Page Flows。
  • vs Dribbble/Pinterest：本条目收录的都是真实产品实现，规避了概念稿与 AI slop——这正是 2025-26 社区从 Dribbble 流向 Mobbin 系的原因 [3]。
