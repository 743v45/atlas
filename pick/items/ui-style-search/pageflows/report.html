Page Flows

TL;DR：完整用户流程的录屏库：看「怎么流」而非「长什么样」的垂直第一；Trustpilot 3.7，个人版定价未核实。
  • 结论：trial 试用
  • 核实日期：2026-09-22

基本信息

项值来源
形态商业闭源：真实产品完整用户流程的录屏视频（Airbnb / Dropbox / Slack 等头部产品）[1]
口碑Trustpilot 3.7/5「Average」；好评「Great UX research, real annotated app flows that save hours」（2026-07/06）[2]
成本免费样本 + 订阅（个人版价格待验证，本次未取得一手定价）[1]

为什么选（作为 trial）

  • 录屏是独占形态：截图库告诉你 checkout 长什么样，录屏告诉你整个 journey 怎么走——静态截图补不了这一环 [1][3]。
  • 「实用主义」口碑：「PageFlows does not try to impress. It helps designers think clearly.」（2026 盘点）[3]。
  • 官网自证言：设计团队称「game changer for our design team」（利益相关，仅作参考）[1]。

为什么不是 adopt

  • 形态垂直（只有流程），不能替代截图库；覆盖限于头部产品的已录流程，长尾产品查不到 [1]。
  • Trustpilot 3.7 不到「优秀」线，有一般性评价存在 [2]。

对比

  • vs Mobbin/Nicelydone：互补而非竞争——库型平台给「屏」，Page Flows 给「流」；重 UX 研究（onboarding/checkout/订阅转化）时先查它。
  • vs UI Sources：同为交互/流程向，UI Sources 偏单点交互，Page Flows 偏完整 journey。

风险与注意

  • 个人版定价未核实（待验证：下次复核补官网定价页一手快照）。
  • 商业闭源，无 gh stats 可刷。
