SmartGit

TL;DR：跨平台功能派：非商业免费、商业 $5/人/月起，含 Linux；界面老派但企业集成最全，教育/开源人群的直接免费项。
  • 结论：trial 试用
  • 核实日期：2026-08-27

基本信息

项值来源
版本官网定价页未展示版本号（当前 major 待验证）[1]
许可证商业闭源 + 三档免费：Hobby（个人非商业，需注册）、学生/教育（教育邮箱）、开源/慈善（用例审核）[1]
仓库无公开仓库（syntevo，德国）—
维护活跃度syntevo 长期经营（SmartGit/SweetScape 系产品线），2026 年定价页持续更新（2026-08-27）；订阅模式自 $4.90/月 起的历史博客可佐证持续运营[1][2]

为什么值得试用

  1. 非商业免费是实打实的：个人非商业、教育、开源、慈善四类免费用全功能（仅缺自托管 GitHub/GitLab/Bitbucket/Azure DevOps 的企业集成）[1]——学生和开源维护者是天然用户（2026-07-28 会话同结论 [5]）。
  2. 商业定价低于 7 月会话预估：官网现挂「From $5/user/month or perpetual licensing」（2026-08-27 查询）[1]，对比 7 月会话的「参考约 $99/年起」口径 [5]，订阅线实际更便宜（$60/年）；买断（perpetual）仍在售。官网已从旧域名 smartgit.com 迁到 smartgit.dev（7 月会话曾遇到搬家补抓 [5]）。
  3. 功能纵深属第一梯队：自托管企业 Git 集成、SSH key 管理（与 Tower 并列被横评点名）[3]、深水 Git 操作覆盖全 [4]。
  4. 跨平台含 Linux：Mac/Win/Linux 三平台，订阅制里比 GitKraken 便宜的选项 [4]。

为什么不是 adopt

  • 审美与交互偏老派 Swing 风，与「轻快 mac 原生」的用户偏好相反（横评普遍将其定位为「重度功能用户」向 [4]）。
  • 主力场景在终端时，它的企业集成纵深用不上，等于为用不到的功能承受更重的客户端。

对比

与 GitKraken 同为跨平台订阅：$5/人/月起 vs $6.99/人/月起，且 SmartGit 有免费非商业档而 GitKraken 免费档仅本地+公开仓库 [1][6]。与 Sublime Merge 同覆盖 Linux：SmartGit 订阅 vs Sublime 买断。逐维度对比见 ../comparison.md。

风险与注意

  • perpetual 与订阅两线的具体差价、升级政策在 docs.syntevo.com，本次未逐条核验（待验证）。
  • 免费档需注册license、开源档需用例审核，有流程摩擦 [1]。
