Tower

TL;DR：功能最全的订阅制老牌：$69–149/年，独有全操作撤销等能力，但个人用户的性价比明显低于 Fork 买断。
  • 结论：hold 观望
  • 核实日期：2026-08-27

基本信息

项值来源
版本Tower for Mac 17.1.1（官网首页，2026-08-27）[1]
许可证闭源订阅：Basic $69/人/年（$5.75/月）、Pro $129/人/年、Enterprise $149/人/年（年付口径）；30 天 Pro 试用；10+ 席 9 折[2]
仓库无公开仓库（fournova Software，德国）—
维护活跃度老牌（2011 年起）、版本迭代至 17.x，维护无虞；自营博客持续产出横评内容（2026 年仍在更新）[1][3]

为什么 hold（个人不推荐新采用）

  1. 订阅定价对个人不友好：Basic $69/年，两年 $138 > Fork 终身 $59.99 的两倍；Pro 档 $129/年（2026-08-27 定价页）[2]，与 2026-07-28 会话快照完全一致，价格未变 [5]。
  2. 功能确实是天花板，但那是团队向的天花板：无限撤销任意 Git 操作、拖拽式交互 rebase、SSH key 管理、团队管理/SSO/统一计费，官方横评自述为「免费替代品中找不到的能力」[3]——这些独占能力集中在重度团队协作，个人场景感知有限。
  3. 大仓库表现过关但不是性能档：dev.to 2025 横评将 Tower 列入大仓库友好组 [4]，但极客口碑里它的「精致」偏功能堆叠，轻快度不及 Fork/Sublime Merge [3]。

什么场景重新考虑（hold 的例外口）

  • 团队采购、需要 SSO/计费/部署管理等企业能力（Enterprise 档），或重度依赖「无限撤销」保命——学生/教师另有免费教育计划（education license，官网专页）[5][6]。

对比

vs Fork：功能更全 vs 一次付费 + 更轻快；个人线 Fork 胜、团队线 Tower 有理由。vs GitKraken：同为团队向订阅，Tower 无免费档但 UI 更传统稳重。逐维度对比见 ../comparison.md。

风险与注意

  • 订阅制：停止续费即失去使用权（与买断制本质差异）。
  • 仅 macOS/Windows，无 Linux [2]。
  • 教育免费计划的当前申领条件在官网 students 页，2026-08-27 未逐条核验（待验证）[6]。
