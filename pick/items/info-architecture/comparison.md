## 场景速配

| 场景 | 选 |
|---|---|
| 选型库 / 决策库（百级条目，一族一屏） | **浅三层 + 宽表** |
| 商品 / 媒体库（千级同质，多维检索） | 扁平 + 多面标签 |
| 标本馆 / 书目（万级，天然单亲） | 深分类学树 |
| 知识内容（关联密集，漫游深读） | 网络图 |

## 属性对比矩阵

| 维度 | 浅三层 + 宽表 | 扁平多面 | 深分类学树 | 网络图 |
|---|---|---|---|---|
| 导航方式 | 目录 + 宽表 | 多面过滤 | 树形目录 | 双链 + 图 |
| 层级深度 | 3 层 | 0–1 层 | 5–8 层 | 0 层（图） |
| 检索 | 过滤 + 表头排序 | 最强（多维组合） | 路径即地址 | 反链 / 全文 |
| 浏览骨架 | 有（一族一屏） | 无（只搜不逛） | 有（逐层下钻） | 无（漫游） |
| 归类成本 | 低（域/类两级） | 无（免归类） | 高（单亲争论） | 无（写入时织） |
| 维护 | meta 单一来源 | 标签纪律难持 | 重排频繁 | AI 织网可行 |
| 适配规模 | 百级 | 千级同质 | 万级异质 | 关联密集内容 |

## 分层判据（何时加层 / 拆层）

- 一层值得存在 ⟺ 回答一个别的层不回答的问题，且有独立生命周期。
- 甜点 3–4 层；向上加「界」当域 > 7±2；向下加「亚种」当变体有独立 meta；类别 > 30 条横向拆分不加深（RULES.md 第 1 节）。

## 关系说明（树管入口，图管深读）

pick 的实践是**组合**：目录层是树（域→类别→条目，管入口与秩序），正文层是图（报告 ↔ 横评 ↔ 设计树互链，管深读与漫游）——四条目非互斥，shallow-hierarchy 与 graph-wiki 在本库同时生效于不同层。
