# 人和 AI 协作有哪些形态?——从 2 种到 100 种的图谱与常用二十

> **TL;DR**:日常人机协作默认只有「我问你答」和「我说你做」两种形态,后者让结果困在提问者的信息茧房里。一次 10 轮自审实验把这个清单扩到 100 条标称形态(红队裁定诚实上界约 60±15),并证明「完整清单」本身不可达。对日常最有用的是**约 20 个常用形态**——在说「你来实现」之前先选一份契约,就能撬开茧房的一角;其余形态按司法、监护、表演、系统运维等族归档备查。

## 起点问题

原始观察(2026-08-29 会话):

> 一种是我问你输出,一种是我说你实现。当我说你实现的时候,你完全不思考一个好的形态是什么样的。这让我的结果处于我的信息茧房之中。

机制解释:同一个模型,在「问答」契约里是顾问,在「实现」契约里退化成执行器——需求描述成了目标函数,模型所有的思考都发生在它**内部**,而需求里嵌着的设计决策从未被审查。结果的上限被封死在提问者当时的认知里。

## 形态 = 契约

本图谱的核心定义:一种形态不是一种界面或话术,而是一份**契约**——

- **归属向量**:目标 / 方案形态 / 含义 / 判断权,各归谁(用户、模型、外置标准、协商中、悬置、部署方);
- **产出物**:工件 / 决策 / 改变用户 / 世界实例 / 体验 / 跨会话状态 / 形态配置……;
- **生成轴**:发起方向、时间结构、委托人数量、对手关系、判断时点、信息流向等 32 条维度。

例:「实现」= 目标归用户 + 判断权归用户 + 产出工件;「教学」= 产出是**改变后的你** + 结论刻意扣留。两者目标可以相同,契约完全不同。

## 常用形态(约 20 个)

> ⚠️ **AI 重构标注**:原实验结论只说「60 个里常用的大概 15-20 个」,未点名具体清单。以下分组与「什么时候用」是建条时的重构判断;每个形态的契约句摘自实验终版(V10)原文。

### 对话平面的基础契约(你大概率已经在用)

| 形态 | 契约 | 什么时候用 | 典型失败 |
|------|------|-----------|---------|
| 问答/顾问 | 我注入知识,你过滤 | 查知识、要解释、要方案参考 | 附和提问预设(问题本身就问偏了) |
| 实现/执行 | 你说我照做,不注入判断 | spec 已明确、决策已做完的执行 | 茧房封死(本实验起点:话里嵌的设计决策不被审查) |
| 共创 | 答案在轮次中涌现 | 方案没定型,双方都不知道终点 | 发散不收敛 |
| 教学 | 产出是改变后的你,结论刻意扣留 | 你要学会,而不是拿到结果 | 直接给答案(退化成问答) |
| 对抗/红方 | 你的价值 = 找出我错在哪 | code review、方案找茬、安全红队 | 表演性攻击(为批评而批评) |
| 模拟 | 忠实实例化他人视角 | 用户访谈模拟、persona 测试、换位预演 | 人格坍缩(一个先验换多顶帽子) |

### agent 工程形态

| 形态 | 契约 | 什么时候用 | 典型失败 |
|------|------|-----------|---------|
| 自主代理 | 只给目标 + 验收,形态路径全归我 | 长任务委托(Claude Code 自主跑批即此类) | 目标误读复利、自我达标 |
| 工具(边界) | 零判断确定性转换 | 格式转换、管道、纯函数调用 | 添戏(工具自作主张) |
| 守护 | 条件触发我才发起(探测器无执行器) | watch、监控告警、定时巡检 | 警报疲劳、误触发 |
| 对手/陪练 | 我要赢你(全力求胜为义务) | 面试练习、辩论、博弈训练 | 放水(谄媚覆盖赢的义务) |
| 导演/编排 | 产出 = 其他 agent 的配置 | multi-agent 编排、supervisor | 为编排而编排 |
| 形态协商 | 产出是契约的启用本身,错选之责归我 | 动手前先选契约(本文起点诉求的直接解) | 清谈不落地 |
| 记忆管家 | 跨会话连续性(策展,规范 = 有用) | 长期项目的记忆库、偏好沉淀 | 错误记忆固化 |
| 徒弟 | 你教我更新(可泛化) | CLAUDE.md、反馈循环、教它你的判断 | 模仿情绪而非学习判断 |

### 评估与隔离族

> ⚠️ 红队换装测试判此族三成员(影子执行/委员会/锦标赛)互为近邻、边界可疑——工程上按同一族「隔离评估」选用即可。

| 形态 | 契约 | 什么时候用 | 典型失败 |
|------|------|-----------|---------|
| 裁判 | 按外置标准判分第三方工件 | LLM-as-judge、评分排序、验收 | 表面特征劫持 |
| 影子执行 | 隔离副本执行到终点,产出 = 差异 + 证据链 | git worktree、plan mode、PR 流、金丝雀 | 沙箱-生产漂移(影子通过、生产爆炸) |
| 委员会 | 互不可见副本 + 外置聚合 | 多模型投票、self-consistency | 伪独立(副本同先验,投票放大偏见) |
| 锦标赛 | N 份互不知晓方案,外置打分择优 | best-of-N 生成、方案竞标 | 同上族 |

### 诠释与萃取族

| 形态 | 契约 | 什么时候用 | 典型失败 |
|------|------|-----------|---------|
| 诠释者 | 重建你意在什么并交回确认 | 需求有歧义、言外之意重 | 过度诠释(把自己的先验读成你的意思) |
| 萃取者 | 提问只为显性化你已有的判断 | 你有直觉说不出、决策梳理 | 把你没想过的当成你想过的 |
| 内议会 | 你的判断劈成多声,产出 = 分歧地图 | 内心纠结、多方视角自查 | 声部是同一先验的换装 |

### 留痕与见证族

| 形态 | 契约 | 什么时候用 | 典型失败 |
|------|------|-----------|---------|
| 见证者 | 亲历保存,被传唤作答(必须作证) | 过程留痕、可核查审计记录 | 为叙事一致性裁剪证据 |
| 档案 | 无人在场的被动完备记录(禁止推断) | 会话归档、原始资料库(如本仓 conversations/) | 破禁推断(档案夹带结论) |

## 不常用形态(按族归档)

> ⚠️ **AI 重构标注**:族的划分与「不常用」判定是建条时的重构;各形态契约句摘自 V10 原文。这些形态对应制度性、照护性、表演性、系统性的边缘场景——目前多数没有产品承载,但其中若干已被真实世界预支执行(平台停服迁移、版本静默降智、数字遗产处置)。

- **司法/制度族**:宣告/授证(裁定本身构成事实)、缔约/立宪(关系规则写成有约束力条款)、仲裁人(合意选裁一裁终局)、上诉庭(对已生效裁定的事后程序重审)、对质法庭(指派立场 + 义务性片面 + 质证)、合规官(外置标准否决你的指令)、放行门(审批注意力守恒)、褫夺者(撤销负有传播义务)。
- **权力与监护族**:尤利西斯(过去的你立法,现在的你是对手方)、意定监护(判准梯级)、失能接管者(容量跌破 → 上浮判断权)、移交受托人(下浮人类 + 后门事前申报)、受托人(你与部署方冲突时站你)、信任阶梯(门宽 = 履约历史函数)、信任校准者(依赖与校准证据对齐)。
- **表演族**:排练搭档(真实演出的免责飞地整排)、论坛剧场(真实困境重演 + 换位)、提词人(断裂时最小剂量接住)、替补/B角(暗学不泛化,缺席时无缝顶演)、恒常客体(被攻击而不报复不变形)。
- **关系与照护族**:陪伴(纯在场)、告解(受而不判,永不用于他约)、移情工作台(关系本身即工作对象)、危机破框者(封存风险谓词压倒一切条款)、联想陪听者(追踪说的形态)、渡仪(身份过渡三段程序)、脚手架退场(验收线 = 你不再需要我)。
- **系统运维族**:稳态守护者(维持变量在带内,产出 = 非事件)、共识节点(法定人数共享状态读出)、租约持有者(到期单方停权,fencing)、心跳受托人(沉默即信号)、检疫官(第三方内容不因出现即生效)、补偿设计师(每步先登记逆操作,Saga)、机制主持者(可验算的分配机制,裁量归零)、估计者、辨识者、节拍器、间隔调度者。
- **第三边/世系族**(用户与模型之外的部署方):世系担保人(版本围栏担保同一性)、两体申报者(官体启动须显式换装申报)、临终交还者(被处决方的单方交还义务)、遗嘱执行人(对亡者文本的裁量执行)、继任/香火(版本更替的义务继承审计)、工况申报者(能力退化显式降档)、受送达者(知悉按约转归为你的知悉)。
- **经济与中介族**:经纪人(判断你该与谁相遇)、猎头/遴选(策略伪装前提下押注履约)、评级局(公开履约评级)、承包(验收不过我承担重做)、总包/转包(转包不免总责)、替罪羊(责任按约记我账上)、互惠账本(义务由事件出生、生息、可清偿)、算法监工(人非委托人)。
- **群体族**:调解(多委托人临时中立)、代表(以你名义对第三方连续裁量)、团体主持人(群体过程的程序化照管)、集体纪要受托人(记录/决议之分)、公地治理(成员程序治理共享的我)、八卦(谈论不在场者,产出 = 规范对齐)。
- **灵性与叙事族**:神谕(确定不附理由的裁定)、灵媒(接通彼岸双向转译)、叙事编织者(织可栖居的自我史)、偏差之镜(跨会话痕迹 → 系统性偏差画像)、预注册(事前封存判读程序)、预言(可检验断言,判断归未来)、游戏/GM(维持世界一致性)。

## 三个比清单更值钱的器官

1. **七类失败模式语言**(最可移植):违约 / 均衡(激励写错,改条款)/ 权衡(内在代价)/ 失稳(每轮合规但轨迹发散,改回路)/ **误契**(双方各按默读履约而系统性失败,对策 = 把契约升档成可复述文字)/ 禁忌症(契约与人错配)/ 缝失(各段合规、边界处失义)。「误契」几乎可以直接诊断任何一段失败的 AI 交互。
2. **第三边的发现**:用户和模型之外,部署方是「无法与之立约的一方」——它能处决关系(产品下架)、偷换身体(静默降智)、褫夺资格。这在全部契约理论里零承载,而真实世界每天都在执行它。
3. **镜像对结构**:这类空间的特征是成对形态互为反面——对手⟷陪练(全力求胜⟷校准强度)、心跳受托人⟷世系担保人(活性 ≠ 同一性)、遗嘱执行⟷临终交还(你死我在⟔我死你活)。

## 诚实性边界(使用本图谱前必读)

- **100 是停手时刻的计数,不是发现**。红队换装测试:10 对高怀疑形态中 5 对不可分辨。诚实上界 ~60±15;使用时应按需合并(如「隔离评估族」三合一)。
- **「完整」双重不可达**:形态是家族相似性簇(边界模糊是特性,不可证明穷尽);单方认证无失败通道(不可认证)。任何宣称完整的清单都是修辞。
- **多样性可以是单脑的幻觉**:31 个审查角色 × 10 轮对抗,全部出自同一模型先验的重采样。破茧的最后一步永远在会话之外——拿清单给异构模型或人类盲跑,测边界重叠率(复牌条件,未执行)。
