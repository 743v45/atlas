Serverless GPU 生意账:GPU 不是资产是期权

TL;DR:「模型放一个地方、机器放一个地方、计算就是调度」的设想真实存在,就是 Serverless GPU / 存算分离推理——Modal、RunPod Serverless、Baseten、Replicate、Fal.ai 整个行业。生意账的核心判断:GPU 不是资产是期权——scale-to-zero 模式下卖不掉,月沉没约 100 元随时归零;卖得掉,自部署把单条成本从官方 API 的约 9 元压到 7 毛以下。止损线:4 周 + 200 元没首单 → 关掉。

一、设想的正规形态:存算分离推理

「模型权重放存储桶、机器按需拉起、计算就是调度」——这就是 Serverless GPU。但有三个工程修正,恰恰是「调度专业性」所在:

  1. 权重放存储桶 ✓,但取的时机是「机器冷启动时」,不是「每个请求时」。权重 15~140GB,从桶里拉要分钟级,GPU 算一次只要秒级。现实是:机器拉起 → 拉一次权重进显存 → 常驻跑几百个请求 → 空闲久了才释放。
  2. 计算不是完全无状态。KV cache 和连续批处理(continuous batching,把不同请求拼进同一批提高利用率)都在单机显存里,所以调度器要做会话亲和、冷启动权衡、缩容时机。
  3. 「所有开源模型统一调度」= Replicate 的产品形态:一个平台几千个模型,每个模型一个 worker 池,路由层按模型分发。模式已被验证。

平台格局(2026 年评测共识):RunPod 赢在价格+冷启动+卡型多(A100 约 $1.42/hr,serverless 4090 约 $0.88/hr);Modal 赢在灵活性(Python 写个函数就部署);Baseten 赢在生产级稳定;Replicate 开源模型即插即用;Fal.ai 视频/图像生成专用管线。国内:阿里云 PAI-EAS、GMI Cloud、AutoDL/仙宫云/恒源云(纯租卡,调度自理)。

关键推论:调度器已经被平台商品化了。不用自己买机器搭集群,写个 handler 丢上去,弹性伸缩、队列、权重缓存全是现成的。

二、生意账:以 H3(开源 33B 全模态视频模型)为例

H3 是教科书场景:量化(INT4/INT8/nvfp4)后权重 ~20GB 级、单张 24G 卡装得下;视频任务分钟级、无会话粘性 → 冷启动拉一次权重、跑一批、空载缩容到零,一台都不用囤。

为什么必须自部署(转发官方 API 没有套利空间):

模式单条成本(15s 视频)卖 2 元的结果
官方 API 768p 档($0.08-0.09/s)~9 元亏 7 元/条
自部署 serverless 4090~0.66 元赚 1.34 元/条

自部署单条成本 ≈ GPU 时租 × 生成分钟 ÷ 60 + 冷启动摊派 ≈ 6.3 × 5/60 + 0.13 ≈ 0.66 元/条(假设单条 GPU 时间 5 分钟——这是整个账的地基,须花 20 块实测;3 分钟则 0.45 元,10 分钟则 1.2 元,生意逻辑就变了)。

月账(日均 50 单假设):GPU 计算费 ~790 + 冷启动摊派 ~190 + 权重存储 ~50 + 交付 ~15 ≈ 1,050 元/月,收入 3,000,毛利 ~65%。

三、纠偏与风险(比账单更容易杀死生意的四条)

  • 纠偏:GMI「minimax-week」免费名单是 M3(文本)/M2.7/Speech/Music——不含 H3 视频,免费活动对视频生意白嫖不到。核查免费额度覆盖哪些模型,别拿活动页标题当事实。
  1. 内容合规(最大风险):国内《AIGC 内容标识办法》要求生成内容打标;开放生成服务,客户产出的内容出事,责任链到你。群里熟人接单风险低,做公开 API 必须上审核——比 GPU 贵得多的成本。
  2. 防刷/账单失控:serverless endpoint 泄露 = GPU 被刷爆,一夜几百刀。前面必须挡一层开源网关 one-api / new-api(管用户、key、限额、计费)。
  3. 支付门槛:海外平台要外币卡;国内替代有 Atlas Cloud、阿里云 PAI-EAS 等。
  4. 冷启动延迟:缩容到零后首单等 3~5 分钟。常驻热待机 ~150 元/天,起步阶段不划算——设 min=0,跟客户说「高峰首单稍等」。

四、卖不掉咋整:GPU 是期权

scale-to-zero 模式下,「卖不掉」本身就是免费选项:没请求 → 没 GPU 时间 → 月账单只剩权重网络盘 ~50 + 网关小鸡 ~10-30,合计 ~100 元/月,随时关掉归零。对比囤机器——几万块压死在折旧里。

一句话:这个生意里 GPU 不是资产是期权——卖不掉,权利金就 100 块/月;卖得掉,行权价 7 毛一条。囤机器才怕卖不掉,按量调度不怕。

卖不掉通常死在三件事:没流量(90%)、没信任(怕跑路)、形态不对(卖 key 这个动作筛掉大部分客户)。

出路四条(按推荐顺序):

  1. 第一个客户是自己——用 H3 生成自己业务的带货素材,把 GPU 时间用掉,顺手攒成品案例。
  2. 换形态:卖成品,不卖 API——客户发素材、你出成品视频、按条收 5~20 元。客单价翻 10 倍,客户感知「代做服务」,信任问题直接消失。
  3. 换客户:to B 电商商家——一天几十条商品视频,价格敏感只看交付,一个商家顶 50 个群友。
  4. 免费换启动——前 50 条免费送,条件是反馈和转发;边际成本 7 毛/条,50 条 35 块,比广告便宜。

止损线:4 周 + 花掉 200 元还没首单 → 关掉归零退出。模式允许随时再开——模型出 Turbo LoRA 提速、成本再降时,随时回来重试。
