# asked — 记录规则

问答馆:「我问、AI 长答、值得留存的一切」。这是图书馆,不是结论馆——收的是讲义,不设定案门槛。

## 1. 什么算一条

- 一次真实的问答:你问了,AI 长答了,内容值得留存——技术原理、概念解惑、方法论讲义(审美怎么积累也算)。
- **自洽是硬标准**:没读过原对话的人能独立看懂——不写「如上所述」「前面提到」,术语首次出现即解释。
- 定义域之外(去别的馆):「怎么做某类任务」的方法 → apprentice;带对比与 verdict 的选型 → pick;翻车 → mistakes;没走通的念头 → spark。
- 单层 `items/<条目>/`;条目 >9 且类型分化明显时再分类(结构判据同 apprentice)。

## 2. meta 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| name | ✓ | 问的那个问题(标题即问题) |
| date | ✓ | 问答日期 YYYY-MM-DD |
| source | ✓ | 源对话归档路径(相对本馆根,跨馆用 `../`,如 `../conversations/xxx.md`)——**写了就必须存在**,知识要准确可溯 |
| tags | ✓ | 标签,非空数组 |

## 3. 写作规范

- **TL;DR 开头**:一段引言说清这篇回答什么问题、结论是什么。
- **忠于当时的答案**:恢复自历史对话的条目,以原答案为骨架;重构补全的部分标注「AI 重构」——存档馆不许无痕改史。
- **出处三件套**:source 归档 + (可选)原始会话文件指针 + 恢复说明。
- 知识会陈旧但不设状态机:内容过时了直接改正文并记变更,不做 outdated 流转(与 apprentice 的差别:方法过时要停用,知识过时要更新)。

## 4. 引擎

渲染器在 `atlas/shared/render.py`(全馆共用),本馆 build 无本地副本。HTML 由 `python3 scripts/build-index.py` 生成,禁止手改;门禁:必填字段、source 存在性、TL;DR 必在、tags 非空。
