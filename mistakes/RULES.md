# mistakes — 记录规则

错题集:一次真实翻车一条错题。主语是学徒——记的不是世界多坑,是我怎么摔的。

## 1. 什么算一条错题

- 一次**真实发生的翻车**,可追溯(meta.source:哪次对话 / 哪个项目 / 哪天)。
- 三段完整叙事:`## 经过`(症状,当时怎么错的)、`## 根因`(错在哪个判断上)、`## 修正`(改成了什么才通)。
- **单一事实源**:apprentice 课的翻车小节只留一行摘要 + 链接;根因与修正的完整档案只住本馆。改错题当天同步对面的链接摘要。
- 结构:单层 `items/<错题>/`,暂不分类。**条目 >9 或类型分化明显时再引入类别层**(与 apprentice 第 1 节结构判据同源)。

## 2. meta 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| name | ✓ | 错题名,症状式命名(「「我想要的」:Z 没说清就动手」) |
| date | ✓ | 翻车日期 YYYY-MM-DD |
| source | ✓ | 出处:哪次对话 / 项目 / 场景(对话类出处归档于 `atlas/conversations/`,建条当日落地) |
| tags | ✓ | 错误类型标签,非空数组——模式识别的锚点(我在哪类错上反复摔) |
| status | ✓ | `fixed`(已修正)/ `recurring`(同一根因又犯——最高警示) |
| related | | 关联路径数组(课 / 修复产物),相对本馆根。**写了就必须存在** |

## 3. 写作规范

- **结论先行**:TL;DR 一句话——错在哪,不在哪。
- **根因必须落在判断上**,不落在情绪上:「我以为是 X,其实是 Y」是合格的根因;「太着急了」不是。
- **修正必须可复用**:写改成了什么动作 / 什么判据,不写「下次小心」。
- 同一根因再犯:原错题 status 改 `recurring`,在「经过」追加一行的复发记录,并重读修正段——修正失效本身就是新信息。
- 错题不过期,无时效字段:历史事实不腐烂,但 `recurring` 是活的警示灯。

## 4. 引擎

渲染器与基础样式在 `atlas/shared/render.py`(三馆与门户共用)。本馆 build 内不得出现本地渲染器副本(check-drift 反向断言看守)。所有 HTML 由 `python3 scripts/build-index.py` 生成,禁止手改;门禁不过的错题不进索引。
