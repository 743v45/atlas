# 2026-08-04~05 · codegraph 官网 UI 像素级复刻

复刻对象是公开站(codegraph 官网),本地重建一份同款页面。会话从「分析」到「一模一样」再到逐格验收,长出一套**像素级验证法**。

**原始表述(三句,逐步收敛)**:

1. 「(目标站 URL) 分析这个网站的 UI 设计」——先分析,不动手;
2. 「文案用官方的。你在这里写一份。一模一样的」——「一模一样」四个字就是验收标准,但它是形容词,要落地成可核对的判据;
3. 「(本地预览页) 页面顶部做得不好」——AI 自认完成后,用户点名具体不满区域。

**关键转折**:肉眼/截图对比反复说「差不多」却总差一点,于是把验收换成**逐元素 computed style 坐标/尺寸对照表**——每个元素一行,原站与复刻各一列,格式如 `24,22/104×20 ✓`(x,y / 宽×高,逐项打勾)。对照表揪出两个此前肉眼漏掉的根因:

1. **漏掉默认 `<style>` 里的 `@media` 断点**——只复了主样式,响应式分支缺失,窗口一变布局塌陷;
2. **字号误用**——用视觉近似值替代精确值,整体「感觉对但说不出的别扭」在表上现形为具体差值。

用户点名「顶部做得不好」后,不是整页重做,而是回到对照表单核该区域的每一格。

**最终结论(沉淀)**:「像不像」要变成**数得清的差异数**——computed style 是 DOM 的客观读数,肉眼是主观印象;逐格对照表让「一模一样」从形容词变成停机条件(全部 ✓ 才算完)。沉淀为 apprentice 课 [pixel-perfect-replication](../apprentice/items/verify/pixel-perfect-replication/)。
