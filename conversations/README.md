# conversations — 对话归档

三馆的 source 底座:课、错题、报告都要求「从真实对话长出来、可追溯」——归档让追溯落到实文件。

## 规则

- **建馆条目当日**,来源对话归档至此,source 字段从「待归档」变实路径。
- 命名:`YYYY-MM-DD-<主题slug>.md`;头部 frontmatter:`date` / `topic` / `related`(它供养的馆条目链接)。
- 完整版或摘要版均可;**摘要版必须保留三样**:需求的原始表述(翻车的证据)、关键转折(用户怎么修正的)、最终结论(沉淀成了什么)。
- 敏感内容脱敏后入库;本仓公开。
